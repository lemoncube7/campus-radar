# 캠퍼스레이더

## Android 0.4.9 정식 · 빌드 30

[APK 다운로드](https://github.com/lemoncube7/campus-radar/releases/download/v0.4.9/campus-radar.apk) · [변경 사항](https://github.com/lemoncube7/campus-radar/releases/tag/v0.4.9) · [전체 릴리스](https://github.com/lemoncube7/campus-radar/releases)

충남대학교 사이버캠퍼스의 과제·콘텐츠·공지를 모아 확인하고 미제출·미완료 항목의 마감을 알려주는 앱입니다.

### 이번 업데이트

- 실제 로그인과 인증된 학기 조회를 확인한 뒤 계정을 저장합니다. 실패하면 입력창에서 오류를 확인하고 다시 시도합니다.
- 공지·과제 본문 이미지와 첨부파일을 기기 내부에 임시 저장합니다. 이미지는 확대하고 첨부파일은 Android 문서 뷰어로 엽니다.
- 파일당 50MB, 계정별 캐시 300MB입니다. 자동 수집은 회차당 약 100MB·60초이며 미수집 자료는 다음 수집 또는 상세 열기에서 이어갑니다.
- 외부 서버 자료와 댓글은 원문에서 확인합니다. 이미지·첨부파일은 AI에 전송하지 않습니다.

### 설치·업데이트

APK를 내려받아 설치하거나 기존 앱의 정식 업데이트 확인을 이용합니다. 기존과 동일한 서명의 덮어쓰기 업데이트입니다.

로그인 정보는 기기의 보안 저장소에 보관합니다. 수집은 기기에서 사이버캠퍼스에 직접 접속하며, 선택한 AI 기능은 개인 Gemini API 키로 관련 텍스트를 전송합니다. 백그라운드 실행 시각은 운영체제 정책에 따라 지연될 수 있습니다.

### 소스와 검증

Android 소스는 저장소와 릴리스의 campus-radar-android-source.zip에서 확인할 수 있습니다. 자동 테스트 164개와 정적 분석을 통과했습니다. 이번 빌드의 실기기 설치·외부 문서 뷰어 실행은 별도 확인이 필요합니다.

다른 플랫폼 배포 파일과 이전 버전은 전체 릴리스를 참고하세요.
