# 캠퍼스레이더 · Campus Radar

**사이버캠퍼스에 매번 들어가지 않아도, 지금 확인할 과제와 수업을 한눈에.**

캠퍼스레이더는 충남대학교 사이버캠퍼스의 과제·학습 콘텐츠·공지를 모아 보여주고, 새 과제와 마감이 가까운 할 일을 알려주는 앱입니다. 공지에 적힌 시험·제출 일정을 AI로 정리하거나, 강의계획서로 시간표를 만들 수도 있습니다.

과제를 확인하려고 로그인하고, 과목별 강의실을 하나씩 열고, 마감일을 다시 캘린더에 옮기는 번거로움을 줄이기 위해 만들었습니다.

[설치 파일 받기](https://github.com/lemoncube7/campus-radar/releases) · [처음 사용하기](#처음-사용하기) · [AI 설정](#ai는-선택해서-사용합니다) · [문제 해결](#문제가-생겼다면)

> 충남대학교 공식 앱이 아닌 개인 개발 프로젝트입니다. 현재 충남대학교 사이버캠퍼스를 대상으로 개발하고 있습니다. 제출 여부·최종 마감일·휴강 및 보강은 학교 원문을 기준으로 확인해 주세요.

## 무엇을 할 수 있나요?

### 해야 할 일을 모아서 확인

- **과제·콘텐츠 목록**: 과목별로 흩어진 항목의 마감, 남은 시간, 제출·완료 상태를 확인합니다.
- **검색·필터·정렬**: 과목과 항목 종류로 좁혀 보고, 제출 완료 과제도 다시 확인합니다.
- **숨기기·복구**: 하지 않아도 되는 항목은 목록에서 숨기고, 필요하면 복구합니다. 학교의 과제를 삭제하는 기능은 아닙니다.
- **공지 모아 보기**: 여러 과목의 공지를 한곳에서 찾고 본문을 읽습니다. 상세 화면에서 사이버캠퍼스의 해당 경로로 이동할 수 있습니다.

### 놓치기 전에 알림

- 수집 중 **새 과제·새 공지**를 발견하면 알립니다.
- **미제출 과제·미완료 콘텐츠의 마감 24시간 전** 알림을 제공합니다.
- 정해진 시각의 **하루 요약**, 저장한 시간표에 따른 **수업 전 알림**을 설정할 수 있습니다.
- 수집 기록과 알림 요청 기록은 **활동 로그**에서 확인합니다.

새 항목 알림은 학교 서버가 즉시 보내는 푸시가 아니라, **앱이 다음 수집에서 발견한 시점**에 발생합니다. 이미 예약한 마감 알림도 마지막으로 수집한 정보를 기준으로 하며, 제출·마감 변경은 다음 성공 수집에 반영됩니다.

### 일정과 시간표까지

- **주간 시간표**: 실제 강의계획서를 순서대로 읽어 수업 시간을 정리합니다. 추출 결과를 확인하고 표시할 수업을 선택할 수 있습니다.
- **캘린더 연결**: Android에서는 선택한 기기 캘린더에 과제·콘텐츠 마감과 확정한 공지 일정을 전송합니다. Windows에서는 `.ics` 일정 파일을 저장합니다.
- **과목 약자**: `컴퓨터프로그래밍2 → 컴프2`처럼 자주 쓰는 이름을 직접 지정합니다.
- **Android 위젯·잠금화면**: 할 일·시간표 홈 화면 위젯과 선택형 잠금화면 카드를 제공합니다.
- **라이트·다크 모드**: 시스템 설정을 따르거나 원하는 테마를 선택합니다.

### 필요한 경우에만 AI 사용

개인 Gemini API 키를 연결하면 **공지의 일정 추출, 일정 후보 검토, 선택형 자동 승인, 하루 요약, 학업 정보에 관한 채팅**을 사용할 수 있습니다. 키 없이도 과제·공지 수집과 기본 알림, 시간표를 사용할 수 있습니다.

**정식 버전**은 일반 사용을 위한 배포이고, **개발 버전**에는 먼저 확인할 새 기능과 화면 변경이 들어갑니다. 개발 버전은 사용 중 문제가 생길 수 있습니다. 아래 주요 화면은 **Android 0.5.5 기준**이며, Windows·iPhone과 이전 버전은 메뉴 배치가 다를 수 있습니다.

iPhone은 Android와 별도로 업데이트합니다. 이 README의 Android 위젯·잠금화면 기능이나 최신 화면 구성이 iPhone에도 모두 적용되어 있다는 의미는 아닙니다.

### Android

1. 원하는 배포의 `campus-radar.apk`를 내려받습니다.
2. APK를 열어 설치합니다. 필요하면 파일을 연 앱의 **출처를 알 수 없는 앱 설치** 권한을 허용합니다.
3. 앱을 실행하고 포털 계정을 연결합니다.
4. 알림 권한과 배터리 설정을 확인합니다. 자세한 방법은 아래 첫 설정을 참고하세요.

기존 사용자는 **앱을 삭제하지 않고 같은 앱 위에 업데이트**하세요. 삭제하면 기기에 저장된 계정·설정·기록을 잃을 수 있습니다.

### Windows

1. `campus-radar-windows.zip`을 내려받아 쓰기 가능한 고정 폴더에 **전부 압축 해제**합니다.
2. 폴더 안의 `campus_radar.exe`를 실행합니다. **EXE만 따로 옮기면 실행되지 않습니다.**
3. 포털 계정을 연결하고 `설정 → PC 실행 설정`에서 자동 수집과 PC 알림을 확인합니다.
4. 원하면 **Windows 로그인 시 자동 실행**을 켭니다. 다음 로그인부터 트레이로 시작합니다.

창의 닫기 버튼을 누르면 트레이에 남습니다. 완전히 끝내려면 트레이 메뉴에서 **종료**를 선택하세요. PC 절전·종료 중에는 수집과 알림 확인이 동작하지 않습니다. 앱 폴더를 옮겼다면 새 위치에서 자동 실행 스위치를 다시 켜 주세요.

사이버캠퍼스·강의계획서를 여는 화면에는 Microsoft Edge WebView2 Runtime이 필요합니다.

## 처음 사용하기

### 1. 포털 연결과 첫 수집

앱에서 **충남대학교 포털 ID와 비밀번호**를 입력해 연결합니다. 연결 후 수강 과목과 과제·콘텐츠·공지를 가져옵니다. 필요하면 오늘 화면의 **지금 확인**으로 다시 수집할 수 있습니다.

첫 수집이 끝나면 과목 목록이 실제 수강 목록과 맞는지 확인해 주세요. 네트워크 오류가 났다면 활동 로그를 보고 다시 시도합니다.

### 2. 알림이 동작할 환경 만들기

**Android**

- 앱의 알림 권한을 허용합니다.
- 기기 설정에서 캠퍼스레이더의 **앱 배터리 사용량을 ‘제한 없음’**으로 설정합니다. 메뉴 이름은 기기마다 다를 수 있습니다.
- 앱의 `설정 → 배터리·백그라운드 상태`에서 상태를 확인합니다.
- 수업 알림 등에 정확한 알림 권한 안내가 나타나면 해당 설정도 확인합니다.
- 알림 표시 테스트로 기기의 알림 설정을 확인할 수 있습니다.

Android는 약 **1시간 간격의 백그라운드 수집**을 요청합니다. 실제 실행 시각은 Android와 제조사의 배터리 정책에 따라 늦어질 수 있습니다. 앱을 강제 종료한 경우에는 다시 실행해 주세요.

**Windows**

`설정 → PC 실행 설정`에서 **자동 수집, 수집 간격, PC 알림, 시작프로그램**을 선택합니다. 수집 간격은 15·30·60·120분 중 선택하며, 기본값은 60분입니다. 수업 전·마감 등 알림 조건은 앱 실행 중 약 1분마다 확인합니다.

### 3. 필요에 따라 시간표·캘린더 연결

- **시간표**: `일정 → 시간표 → 시간표 만들기`를 누릅니다. 과목별 강의계획서를 불러온 뒤 주간 표와 실패·시간 미확인 과목을 확인합니다. 시간표의 알림 설정에서 수업 전 알림 시점과 종료일을 정할 수 있습니다.
- **Android 캘린더**: `설정 → 캘린더 전송`에서 권한을 허용하고 저장할 캘린더를 선택합니다. 자동 전송은 원하는 경우에 켭니다.
- **Windows 일정 파일**: `설정 → 일정 파일 내보내기` 또는 항목 상세에서 `.ics` 파일을 저장해 사용 중인 캘린더로 가져옵니다. 가져온 파일은 자동 갱신되지 않습니다.

시간표는 강의계획서에서 읽은 정규 수업 기준입니다. 휴강·보강·시험으로 바뀐 수업을 자동으로 모두 반영하지는 않습니다.

## 평소에는 이렇게 사용하세요

| 화면 | 하는 일 |
|---|---|
| **오늘** | 가까운 마감, 오늘 수업, 최근 공지와 확인이 필요한 일정을 빠르게 봅니다. |
| **할 일** | 과제·콘텐츠를 검색·필터링하고 진행 중·제출 대기·제출 완료·숨긴 항목을 확인합니다. |
| **과목** | 과목별 과제·공지·강의계획서를 확인하고 과목 약자를 설정합니다. |
| **더보기** | 시간표·캘린더·AI 검토함과 기능 안내를 열고, 연결·알림·테마·위젯·AI·기록·업데이트를 관리합니다. |

알림을 누르면 관련 항목이나 목록으로 이동합니다. 상세에서 **사이버캠퍼스 열기**를 누르면 해당 학교 페이지로 이어집니다. 과제 제출은 사이버캠퍼스에서 진행합니다.

### 업데이트 내역과 세션 재연결

- **더보기 → 기록·앱 관리 → 업데이트 내역**에서 버전마다 바뀐 내용을 확인합니다. 업데이트 화면에서도 열 수 있습니다.
- **정식 모드**는 정식 내역만, **개발 모드**는 정식·개발 내역을 구분해서 보여 줍니다. 내역 화면의 모드 선택은 받을 업데이트 채널을 바꾸지 않습니다.
- 새 버전이 있거나 업데이트 직후라면 **이번 업데이트에 포함된 내역만**으로 건너뛴 버전 사이의 변경을 순서대로 볼 수 있습니다. 전체 내역으로 전환할 수도 있습니다.
- 내역은 앱에도 포함돼 있어 오프라인에서 볼 수 있습니다. 최신 내용은 내역 새로고침으로 확인합니다.
- 학교 연결은 저장된 세션부터 재사용합니다. 인증이 종료되면 다른 기기 로그인 가능성을 고려해 기본 **2시간** 대기한 뒤 다음 수집에서 재연결합니다. **더보기 → 학교 연결·수집 → 백그라운드 상태**에서 대기 시간을 변경할 수 있습니다.
- 이전에 숫자로 지정한 대기는 보존합니다. 이전 버전은 미설정과 ‘직접 재연결’을 구별해 저장하지 않아 둘 다 기본 2시간으로 바뀝니다. 새 버전에서 직접 재연결을 선택하면 이후에도 유지합니다.

### Android 홈 화면 위젯과 잠금화면

`더보기 → 화면·위젯 → 위젯·잠금화면`에서 안내를 확인합니다.

- **홈 화면 위젯**: 홈 화면을 길게 누르고 위젯 목록에서 캠퍼스레이더의 할 일 또는 시간표 위젯을 추가합니다.
- **잠금화면 카드**: 잠금화면 정보 설정에서 접근성 서비스 안내를 확인한 뒤 직접 켭니다. 작은 카드·전체 카드를 선택할 수 있습니다.
- 작은 카드는 크기·위치·불투명도를 조절할 수 있고, 위젯 글씨 크기도 설정할 수 있습니다.
- Android에서 앱을 **강제 종료**하면 접근성 서비스가 꺼질 수 있습니다. 카드가 나오지 않으면 접근성 설정에서 다시 켜 주세요.
- 잠금화면 표시는 기기 설정과 제조사에 따라 다를 수 있습니다. 과목명·과제명이 잠긴 화면에 보이는 것이 괜찮은지 확인하고 사용하세요.

## AI는 선택해서 사용합니다

### 연결

1. `설정 → AI 연결·일정 자동 정리`를 엽니다.
2. 화면의 **키 발급·무료 등급 확인** 링크에서 개인 Gemini API 키를 준비합니다.
3. 어떤 자료가 Google로 전송되는지 읽고, 동의한 경우 키를 저장합니다.
4. **공지 자동 순차 분석**의 범위를 선택하고 자동화 설정을 저장합니다. 수동으로 공지 하나만 분석할 수도 있습니다.

앱에서 키 발급과 사용량 한도 확인 페이지로 이동할 수 있습니다. 실제 사용 가능 모델·무료 한도·요금은 본인 Google 프로젝트의 상태를 확인하세요.

### 일정 검토와 자동 승인

공지에서 찾은 일정은 **일정 → 확인 필요**에서 원문 근거와 날짜·시간을 확인한 뒤 확정하거나 수정할 수 있습니다. 일정이 아닌 후보는 제외할 수 있습니다.

선택 기능인 **명확한 AI 일정 자동 승인**을 켜면 Gemini가 원문과 후보를 다시 검토합니다. 조건을 만족하는 일정만 자동 확정하고, 불확실하거나 변경·취소 관련인 후보는 검토 대상으로 남깁니다. 캘린더 전송 여부는 별도의 캘린더 설정을 따릅니다.

분석이 실패하면 문제 해결 화면에서 원인과 가능한 조치를 확인할 수 있습니다. 재시도, 선택한 관련 자료를 추가한 재분석, 직접 일정 추가, 분석 제외를 상황에 따라 선택합니다.

AI가 만든 일정이나 시간표를 참고한 추정은 틀릴 수 있습니다. 특히 시험·제출 일정은 공지 원문과 함께 확인해 주세요.

## 계정과 자료는 어떻게 처리하나요?

- **별도의 개발자 서버를 두지 않습니다.** 앱이 기기에서 학교 사이트에 직접 연결해 수집합니다.
- 포털 ID·비밀번호와 Gemini API 키는 운영체제의 보안 저장소를 이용합니다. 포털 계정·세션 쿠키를 Gemini에 보내지 않습니다.
- 수집한 과제·공지·시간표와 설정·로그는 기기에 저장합니다. **모든 수집 데이터가 별도로 암호화되는 것은 아닙니다.**
- Android·iPhone·Windows의 계정과 데이터는 각각 독립적이며, 기기 간 동기화는 제공하지 않습니다.
- AI를 사용하면 해당 기능에 필요한 공지 본문·과목명·과제 정보·저장된 시간표 등이 Google Gemini로 전송됩니다. 관련 자료를 추가한 재분석과 채팅은 선택한 공유 범위에 따라 전송 내용이 달라집니다. AI 채팅의 질문과 최근 대화도 Google로 전송됩니다.
- 앱 설치와 업데이트 확인은 GitHub를 사용합니다. 외부 캘린더나 브라우저는 사용자가 선택한 기능에서 연결됩니다.

### 할 일 정리와 휴강 반영

- `설정 → 할 일 정리·출석`에서 기한 지난 항목의 확인 후 숨김·즉시 자동 숨김·24시간 후 자동 숨김을 선택합니다. 숨긴 항목은 일정의 숨김 목록에서 복구할 수 있습니다.
- 콘텐츠는 완료 여부와 출석 반영 여부를 따로 표시합니다. 출석 미반영 콘텐츠의 마감 알림도 별도로 선택할 수 있습니다.
- 공지의 AI 휴강 후보에서 **시간표에 휴강 반영**을 누르고 날짜와 수업을 확인합니다. 주간 시간표 원본은 유지하고 해당 날짜의 수업과 알림만 제외합니다. `시간표 → 날짜별 휴강 관리`에서 해제할 수 있습니다.
- 잠금화면 미리보기를 보면서 카드 크기·위치·불투명도를 조절할 수 있습니다. 수업 카운트다운은 시작 후 0~120분 유지하도록 설정할 수 있습니다.

## 업데이트

- **Android**: `설정 → 앱 업데이트`에서 정식·개발 업데이트 설정을 확인하고 새 APK를 설치합니다. 자동 수집 때도 업데이트 여부를 확인합니다.
- **Windows**: `설정 → 앱 업데이트`에서 Windows용 ZIP을 확인합니다. 앱은 다운로드·해시 확인 후 종료하고 파일을 교체한 뒤 다시 실행하는 방식으로 업데이트합니다.
- **iPhone**: [별도 배포 안내](IOS-DISTRIBUTION.md)를 따릅니다. AltStore를 통한 설치·서명 갱신은 Android APK 업데이트와 방식이 다릅니다.

기존 앱을 지우지 않고 업데이트하는 것이 기본입니다. 이전 버전으로 되돌리는 경우에는 OS의 다운그레이드 제한과 데이터 호환성을 별도로 확인해야 합니다.

## 문제가 생겼다면

| 증상 | 먼저 확인할 것 |
|---|---|
| 로그인·수집 실패 | 포털 계정, 인터넷 연결, 학교 점검 여부를 확인하고 **지금 확인**을 다시 실행합니다. `설정 → 활동 로그`에서 실패 내용을 볼 수 있습니다. |
| 과목이나 항목이 빠져 보임 | 필터·숨긴 항목을 확인하고 다시 수집합니다. 계속 같다면 실제 학교 목록과 비교해 주세요. |
| 마감 알림이 오지 않음 | 최근 수집 성공 여부, 제출·완료·숨김 상태, 알림 권한, Android 배터리 제한 또는 Windows 실행 상태를 확인합니다. |
| 강의계획서·시간표 일부 실패 | 실패 과목 안내를 확인하고 잠시 후 다시 만듭니다. 실패한 과목의 기존 시간표는 유지합니다. 원문에 명확한 요일·시간이 없는 과목은 추출되지 않을 수 있습니다. |
| AI 분석 실패 | 문제 해결 화면의 원인, API 키와 사용량 한도를 확인합니다. 필요한 경우 관련 자료를 선택해 재분석하거나 직접 일정을 추가합니다. |
| Windows가 실행되지 않음 | ZIP 전체를 풀었는지, EXE 주변의 DLL·data 폴더가 있는지, WebView2 Runtime이 설치되어 있는지 확인합니다. |

해결되지 않으면 [GitHub Issues](https://github.com/lemoncube7/campus-radar/issues)에 **앱 버전·기기/OS·발생 순서·오류 메시지**를 남겨 주세요. ID·비밀번호·API 키·로그인 쿠키는 올리지 말고, 화면이나 로그에 포함된 학번·개인 정보도 가려 주세요.

## 소스와 개발

앱은 **Flutter/Dart**를 기반으로 하며, Android·iOS의 알림·캘린더·백그라운드 기능과 Windows 트레이·자동 실행 기능을 플랫폼에 맞게 연결합니다. 로컬 자료 저장에는 SQLite를 사용합니다.

현재 저장소는 배포 파일·버전 정보·워크플로와 **소스 ZIP**을 중심으로 관리합니다. 저장소 루트에서 바로 Flutter 명령을 실행하는 구조는 아닙니다.

- Android: 해당 [릴리스](https://github.com/lemoncube7/campus-radar/releases)의 `campus-radar-android-source.zip`
- Windows: 저장소의 [campus-radar-windows-source.zip](campus-radar-windows-source.zip)
- iPhone: [배포·빌드 안내](IOS-DISTRIBUTION.md)

소스 ZIP을 풀고 `pubspec.yaml`이 있는 폴더에서 실행합니다.

```sh
flutter pub get
flutter analyze
flutter test
```

Android 개발 빌드:

```sh
flutter build apk --release --dart-define=RELEASE_CHANNEL=development
```

Windows 빌드에는 Windows C++ 데스크톱 개발 도구가 필요합니다.

```sh
flutter build windows --release
```

계정·API 키·배포 서명 파일은 소스에 포함하지 않습니다. 본인 환경에서 별도로 준비해야 합니다. 현재 기능 범위와 버전별 변경은 [릴리스 목록](https://github.com/lemoncube7/campus-radar/releases)을 참고하세요.
