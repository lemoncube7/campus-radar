# 캠퍼스레이더

충남대학교 사이버캠퍼스 과제·콘텐츠 알림 프로토타입입니다. Android APK를 배포하며 iPhone용 AltStore 테스트 배포를 준비했습니다.

iPhone 빌드·설치·검증 절차는 [IOS-DISTRIBUTION.md](IOS-DISTRIBUTION.md)를 확인하세요. iOS 백그라운드 수집은 고정된 주기를 보장하지 않습니다.

## 설치

Releases에서 campus-radar.apk를 내려받아 설치하세요. Android 8.0 이상을 대상으로 합니다.
앱에서 충남대 포털 계정으로 연결하고 알림 권한을 허용하세요.
계정은 기기에 암호화해 저장하며, 과제 수집은 기기에서 사이버캠퍼스로 직접 요청합니다.

## 0.1.8 Android 추가 기능

- 개인 키를 넣는 선택형 Gemini 3.5 Flash Lite 공지 분석. 공지 상세에서 요청하며 같은 본문은 결과 재사용.
- 근거 원문·날짜 검증과 후보 확인 후 캘린더 저장. 변경·취소는 기존 일정 직접 확인.
- 기기 캘린더 선택, 과제·콘텐츠 개별 전송 및 선택형 자동 전송·연결 일정 갱신.
- AI 요청/결과/실패와 캘린더 저장/갱신 로그. 키는 기기 보안 저장소이며 공용 키 미포함.
- 자동 테스트 32개, 정적 분석, 실제 Gemini 가상 공지 5종 검증 통과. Android 실기기 신규 기능 확인 대기.
- 0.1.7의 업데이트 로그·배터리 제한 경고 포함. iPhone 공개 배포는 0.1.5/build 6 유지.
- 세부 동작/외부 전송/제한은 [RELEASE-NOTES.md](RELEASE-NOTES.md) 확인.

## 기능

- 약 1시간마다 새로 로그인해 과제와 콘텐츠를 수집합니다. 실행 시각은 Android 절전 정책에 따라 지연될 수 있습니다.
- 첫 연결은 기존 과제를 기준 목록으로 저장하고, 이후 새로 발견한 과제를 알립니다.
- 미제출 과제와 미완료 콘텐츠의 마감 24시간 전 알림을 예약합니다. 이미 하루 이내라면 한 번 알립니다.
- 알림을 누르면 앱 상세를 열고, 사이버캠퍼스 바로가기로 연결합니다.
- 제출 완료·마감 변경이 확인되면 알림 예약을 갱신합니다.
- 업데이트 확인 → APK 다운로드·해시·서명 검증 → Android 설치 화면을 제공합니다.

- 상세 화면의 목록에서 제외로 항목과 알림을 숨깁니다. 제외 항목 보기에서 복구할 수 있고, 다음 수집에도 제외 상태를 유지합니다.

## 0.1.4 추가 기능

- 메인 화면의 수집 로그에서 수집 시작·성공·실패, 받아온 과제·콘텐츠·공지의 제목과 상태를 검색해 확인합니다.
- 알림 로그에서 예약·취소·발송 요청·클릭을 확인합니다. 발송 요청은 운영체제가 실제로 알림을 표시했다는 뜻이 아닙니다.
- 기록은 두 화면을 합쳐 기기에 최근 2,000건을 보관합니다. 업데이트 이전의 기록은 복원되지 않습니다. 로그아웃하면 계정과 함께 기록·공지 캐시도 지웁니다.
- 공지 모아보기에서 현재 학기 공지를 최신순으로 모아 보고, 과목 필터·검색을 사용합니다. 본문은 공지를 열 때 직접 수집하고 기기에 저장합니다.
- 공지의 확인 상태는 사이버캠퍼스 목록을 마지막으로 수집했을 때의 값입니다. 본문을 가져올 때 별도로 확인 처리 API를 호출하지 않습니다.
- 첨부파일·이미지·댓글은 공지 상세의 사이버캠퍼스 바로가기에서 확인합니다.
- 미완료 항목은 기한 지남 빨강, 남은 시간 24시간 이내 주황, 24시간 초과 파랑으로 표시합니다. 완료는 초록, 기한 미확인은 회색입니다. 상태 글자도 함께 표시합니다.
- 기존 계정·과제·제외 상태는 데이터베이스를 업그레이드해 유지합니다.

## 검증 상태

### 0.1.6 Android 확장 (실기기 검증 대기)

- 공개 여부와 시작 시각을 저장합니다. 비공개·시작 전 항목은 기본 목록, 홈 위젯, 데일리 요약, 새 과제·마감·변경 알림에서 제외합니다. 수집 로그는 예약 정보를 포함한 원본 수집 기록이므로 전체 건수가 표시 목록보다 클 수 있습니다.
- 실제 계정 조사에서 과제·콘텐츠 34개 중 비공개이면서 시작 전인 항목 12개를 확인했고, 현재 표시 가능 항목은 22개였습니다. 공개 전 기록은 기기에 유지해 이후 공개 전환을 감지합니다.
- 홈 화면을 길게 누르고 위젯 메뉴에서 ‘캠퍼스레이더 과제 현황’을 추가합니다. 가까운 마감 순 최대 4개, 남은 시간과 마지막 수집 시각을 표시하며 항목을 누르면 상세를 엽니다. 수집·제외 상태 변경과 운영체제의 위젯 갱신 시 표시를 갱신하며 초 단위 실시간 카운트다운은 아닙니다.
- 메인 화면의 ‘데일리 요약’에서 오늘 마감·24시간 이내·전체 미완료·오늘 새 과제를 확인합니다. 전체 미완료에는 기한 지난 항목도 포함합니다. 오늘의 기준은 한국 시간입니다.
- 요약 알림은 처음에는 꺼져 있습니다. 시각을 선택한 뒤 ‘매일 요약 알림’을 켜세요. 예약은 기기 현지 시각이며 운영체제 절전 정책에 따라 지연될 수 있습니다. 네트워크 수집과 독립적으로 기기의 마지막 저장 목록을 집계하고 수집 시각을 알림에 표시합니다. 재부팅·업데이트·시간 변경 시 예약을 복원합니다.
- 과제·콘텐츠의 마감·제목·설명 변경을 비교해 알리고 ‘변경 이력’에서 전후 내용을 확인합니다. 제출 상태 변경·공백 차이·첨부파일 변경은 현재 변경 알림 대상이 아닙니다. 첫 수집은 기준 목록으로 저장합니다.
- 자동 테스트 15개 및 정적 분석을 통과했고 APK 0.1.6 / 코드 7 빌드와 서명 검증을 마쳤습니다. 새 Android 위젯의 실제 배치·클릭, 요약 알림 표시·예약 실행·재부팅 복원, 변경 알림의 실제 표시는 기기 연결 후 확인해야 합니다.
- iPhone 배포 채널은 0.1.5 / 빌드 6을 유지합니다. 0.1.6 iPhone 빌드·게시를 실행하지 않았습니다.

### 0.1.5 백그라운드 수집 수정

- Android v0.1.5 정식 Release와 기본 업데이트 manifest를 게시했습니다. 공개 APK를 다시 다운로드해 SHA-256 일치를 확인했습니다.
- iPhone 0.1.5 / 빌드 6도 macOS 빌드·테스트 후 ios-preview에 게시했습니다. 실제 IPA의 버전·번들 ID·파일 크기·SHA-256과 AltStore 메타데이터 일치를 확인했습니다. 실제 iPhone 동작은 확인 전입니다. AltStore Classic 2.3 설치 방식은 iOS 17.4 이상을 요구합니다.

- 전체 할 일 목록 API가 시간 초과되는 문제를 피하도록 강의별 주차 목록과 기타 학습요소 목록을 합쳐 수집합니다. 과제 상세·실제 제출 상태 조회와 기존 항목 식별자는 유지합니다.
- 수집 로그에서 앱 시작·복귀·수동 확인·백그라운드 실행을 구분하고, 실패 단계·요청 경로·오류 종류를 기록합니다. 계정 비밀번호나 통신 토큰은 기록하지 않습니다.
- Android 수집 로그 상단의 백그라운드 상태에서 배터리 제한, 예약 작업, 마지막 백그라운드 성공과 운영체제 실행 기록을 확인합니다. 별도 시험 예약도 제공합니다.
- 2026-10-15 실제 계정에서 과제 10개·콘텐츠 24개·공지 24개를 확인했습니다. 자동 테스트 12개와 정적 분석을 통과했습니다.
- SM-S936N에서 기존 앱 위에 설치 후 수집에 성공했습니다. 10:51에 실제·가상 화면 모두에서 앱을 내린 상태로 Android가 시험 작업을 자동 실행했고, 백그라운드 수집 저장·알림 처리 완료 및 성공 기록을 확인했습니다. 절전 모드는 켜져 있고 앱 배터리는 제한 없음이었습니다.
- 새 과제 발생 시의 실제 알림 표시와 장시간의 정기 1시간 수집은 이번 시험으로 검증하지 않았습니다. 성공한 시험 작업과 정기 작업은 상태 화면에 구분합니다.

실제 계정에서 포털 로그인과 수강 과목·과제·콘텐츠 수집을 확인했습니다.
과제는 실제 제출 기록의 apply_yn 및 임시 저장 여부를 사용하고, 콘텐츠는 complete_yn을 사용합니다.
0.1.1은 실제 Android 16 삼성 기기에서 시작 화면 표시를 확인했습니다. 백그라운드 수집, 실제 알림, 웹뷰 바로가기, APK 업데이트 설치는 추가 확인이 필요합니다.

0.1.4 수집 코드로 실제 계정의 과제 10개·콘텐츠 24개·공지 24개, 공지 본문과 바로가기 경로를 확인했습니다.
연결된 Samsung SM-S936N에서 기존 앱 위에 업데이트 설치했고, 계정 유지·수집 로그·공지 목록·공지 본문·해당 공지 웹뷰 연결·알림 로그의 테스트 발송 요청 기록·마감 색상 표시를 확인했습니다.
정적 분석과 자동 테스트 10개, SQLite 업그레이드 및 로그 2,000건 유지 검증을 통과했습니다. APK의 기존 서명 인증서·패키지명·버전 코드 5를 확인했고, v0.1.4 Release와 기본 업데이트 manifest 게시 및 SHA-256 일치를 확인했습니다.
iOS 0.1.4 IPA도 macOS 빌드와 테스트를 통과해 ios-preview에 게시했습니다. 실제 IPA의 버전 0.1.4 / 빌드 5, 최소 iOS 14.0, SHA-256과 AltStore Source 파일 크기·번들 ID 일치를 확인했습니다. 실제 iPhone의 설치·알림·백그라운드 동작은 아직 확인 전입니다.
학교 공지 웹뷰에서는 사이트 자체의 팝업 차단 안내가 나타날 수 있습니다. 실제 목적 공지의 본문 로딩은 확인했습니다.

## 개발

Flutter 3.35.7 / Dart 3.9.2, Java 17, Android SDK 36을 사용합니다.
소스 패키지 campus-radar-source.zip을 풀고 flutter pub get을 실행하세요.
릴리스 빌드에는 기존 배포와 같은 Android 서명 키가 필요합니다. 서명 키·계정 파일은 공개하지 않습니다.
빌드 설정의 signingConfigs를 자신의 안전한 로컬 서명 설정으로 연결하세요.
flutter analyze 및 flutter test 후 flutter build apk --release로 빌드합니다.

## 업데이트 게시

같은 서명 키로 만들고 versionCode를 증가시킨 APK와 latest.json을 새 GitHub Release에 함께 올립니다.
latest.json에는 versionCode, versionName, apkUrl, sha256, notes가 필요합니다.
앱의 기본 확인 주소는 https://github.com/lemoncube7/campus-radar/releases/latest/download/latest.json 입니다.
SHA-256, 패키지명, 버전, 서명 인증서가 맞는 APK만 설치 화면으로 전달합니다.

학교 공식 앱이 아닌 개인 프로토타입입니다. 실패 시 마지막 성공 데이터를 유지하고 화면에 오류를 표시합니다.
