## 무엇을 할 수 있나요?

### 해야 할 일과 학교 자료 모아 보기

- **과제·콘텐츠:** 마감·남은 시간·제출/완료 상태를 과목별로 확인하고 검색·필터·정렬합니다. 제출 시작 전 항목은 제출 대기 표시 설정으로 관리합니다.
- **숨김과 할 일 아님:** 목록에서 숨기거나, 점수 확인처럼 실제 할 일이 아닌 항목을 별도로 분류합니다. 학교 원본을 삭제하지 않으며 복구할 수 있습니다.
- **공지·자료:** 공지를 한곳에서 읽고, 과목의 자료 탭에서 공지·과제·콘텐츠·자료실 첨부를 출처별로 찾습니다. 기타 학습 항목과 외부 링크·온라인 수업도 확인합니다.
- **이미지·파일:** 이미지는 바로 보고 확대하며, 저장된 파일은 오프라인에서 열 수 있습니다. 자료의 기기 저장 상태를 표시합니다.
- **공개 평가 결과:** 학교가 공개한 본인 점수·만점·피드백을 과제 제목 아래에서 확인합니다. 평가 정보는 새 수집 후 반영됩니다.

### 놓치기 전에 알림

- 수집에서 새 과제·공지·자료 등을 발견하면 알립니다.
- 미제출 과제·미완료 콘텐츠의 마감 알림은 **기본 하루 전**이며 여러 시점으로 설정할 수 있습니다. 직접 입력을 포함해 최대6개, 최대30일 전까지 지원합니다.
- 정해진 시각의 하루 요약과 시간표에 따른 수업 전·자정 알림을 설정할 수 있습니다.
- 수집·알림·AI·캘린더·업데이트 기록을 활동 로그에서 확인하고 파일로 저장·공유합니다.

새 항목 알림은 학교 서버가 직접 보내는 실시간 푸시가 아니라 **앱이 수집에서 발견한 시점**에 발생합니다. 제출·마감 변경은 다음 성공 수집 후 반영됩니다. Android의 백그라운드 정책에 따라 수집·알림이 지연될 수 있습니다.

### 시간표·캘린더·내 방식의 화면

- **계획서 시간표:** 학교 강의계획서에서 수업·시간·강의실을 정리합니다. 최근 저장본 활용과 새로 받기, 진행 표시·취소를 지원합니다.
- **개인 반복 일정:** 요일·시작/종료·장소·메모를 추가하고 수정·삭제합니다.
- **시간표 공유:** 코드 하나로 친구와 시간표 사본을 주고받고 겹쳐 봅니다. 강의실은 선택 포함, 개인 일정은 기본 제외하며 포함해도 바쁜 시간만 공유합니다. **암호화·실시간 동기화 기능은 아닙니다.**
- **캘린더:** 선택한 기기 캘린더에 마감과 확정한 AI 일정을 전송합니다. 휴강 후보는 날짜·수업을 확인해 시간표에 반영하고 해제할 수 있습니다.
- **과목 약자·색상:** 과목 이름을 짧게 지정하고 각 과목의 색상을 정합니다.
- **테마·위젯:** 두 포인트색과 라이트/다크 모드, 할 일·시간표 홈 위젯, 표준 잠금화면 위젯과 선택형 접근성 카드를 제공합니다.

## 처음 사용하기

### 1. 학교 연결과 수집

충남대학교 **포털 ID·비밀번호**로 연결한 뒤 첫 수집이 끝나면 실제 수강 목록과 비교합니다. 오늘 화면의 **지금 확인**으로 직접 수집할 수 있습니다.

백그라운드 수집은 저장된 세션을 먼저 재사용하며, 인증이 끊기면 다른 기기 접속 가능성을 고려해 기본2시간 재연결을 기다립니다. 더보기 → 학교 연결·수집에서 대기 시간을 변경합니다. **앱을 직접 시작하거나 실제로 복귀했을 때와 지금 확인은 대기를 건너뛰고 새로 로그인해 수집합니다.** 학교의 동시 로그인 정책에 따라 다른 기기 세션에 영향을 줄 수 있습니다.

기본 백그라운드 수집은 약1시간 간격으로 요청하지만 정확한 실행 시각을 보장하지 않습니다. 수집 설정과 세션 상태에 따라 동작이 달라질 수 있습니다.

### 2. 알림 권한과 배터리 설정

더보기 → 알림에서 권한과 알림 시점을 확인합니다. 기기 설정의 앱 배터리 사용량은 **제한 없음**으로 설정하는 것을 권장합니다. 메뉴 이름은 제조사·OS마다 다릅니다. 수집 상태는 더보기 → 학교 연결·수집에서 확인합니다.

더보기 → 기록·지원의 **알림 표시 테스트**는 표시와 클릭 경로를 확인하는 용도입니다. 테스트 알림 성공이 장시간 백그라운드 알림 전체를 보장하지는 않습니다.

### 3. 시간표와 캘린더

더보기 → 시간표에서 계획서를 불러오고 요일·시간·강의실을 확인합니다. 시간표에서 개인 반복 일정과 시간표 공유·친구 시간표로 이동할 수 있습니다.

캘린더와 AI 설정은 더보기 → **AI·캘린더**에서 접근합니다. 권한과 대상 캘린더를 선택하고 자동 전송 여부를 설정합니다. 계획서와 AI 추정이 실제 운영과 다를 수 있어 확인이 필요합니다.

## AI는 선택해서 사용합니다

**앱 내부 AI 기능**과 **외부 ChatGPT 플러그인 연결**은 서로 다른 기능입니다.

앱 내부 AI는 개인 Gemini API 키로 공지 일정 분석·일정 후보 검토·선택형 자동 승인·하루 요약·채팅을 제공합니다. 키 없이도 기본 수집·목록·알림·시간표를 사용할 수 있습니다.

1. 더보기 → AI·캘린더에서 AI 설정을 엽니다.
2. 화면의 키 발급·무료 등급/사용량 확인 링크로 본인 Google 프로젝트의 API 키와 한도를 확인합니다.
3. 전송할 자료와 동의 내용을 확인하고 키·자동 분석 옵션을 설정합니다.
4. 분석 결과는 확인할 항목에서 원문 근거·날짜·시간을 확인해 확정·수정·제외합니다.

명확한 일정 자동 승인은 Gemini가 원문과 후보를 재검토하는 선택 기능입니다. 불확실하거나 변경·취소 관련 후보는 검토 대상으로 남기며, 캘린더 전송은 별도 설정을 따릅니다. 실패하면 원인 안내·재시도·선택 자료를 추가한 재분석·수동 일정 추가·분석 제외 등의 경로를 제공합니다.

무료 사용 가능 여부와 한도는 본인의 Google 프로젝트 상태에 따라 달라집니다. AI 결과와 시간표를 참고한 추정은 원문과 대조해 주세요.

## GPT와 학교 자료 연결하기

APK 설치만으로 ChatGPT가 학교 자료에 접근하지는 않습니다. 아래 두 경로는 별개이며 **각각 연결 설정이 필요합니다.**

| 방식 | 현재 상태 |
|---|---|
| **기존 서버형 연결** | 별도로 연결한 서버에 동의한 자료를 동기화하고 플러그인이 조회합니다. 실제 수집 상태·할 일·공지·시간표·자료 텍스트 조회를 확인했습니다. 현재 개인용 연결 범위이며 모든 사용자를 위한 서버 운영을 약속하지 않습니다. |
| **무서버 자료 내보내기** | 앱에서 자료를 만들고 사용자가 저장소에 올린 뒤 해당 저장소 연결로 읽는 방식입니다. 실제 ZIP 생성·저장은 확인했지만 새 Drive 연결 전체 흐름은 미검증입니다. |

### 수동 내보내기 사용 순서

1. 더보기 → AI·캘린더 → **저장소로 AI 자료 내보내기**를 엽니다.
2. 과목과 포함 자료, TXT/Markdown·첨부 추출·선택 원본 옵션을 확인합니다.
3. 미리보기 후 ZIP을 저장·공유하고 압축을 풀어 본인의 비공개 저장소 폴더에 올립니다.
4. ChatGPT에 해당 저장소 연결을 설정하고 시작 문서를 찾아 읽도록 요청합니다. 폴더 링크만 전달해 읽기 성공으로 간주하지 마세요.

학교 계정·키·쿠키·구조화된 점수·친구/개인 시간표는 기본 내보내기 대상에서 제외합니다. 공지·파일 본문 자체의 개인정보는 별도로 검토해야 합니다.

기기에 저장된 첨부에서 최대10개 텍스트를 추출합니다. TXT/MD/CSV/JSON·HWPX/DOCX/PPTX와 Android15 이상 PDF 텍스트를 지원하며, HWP 바이너리·스캔 이미지 OCR·그림/표/배치 보존은 지원하지 않습니다. 원본은 선택한 캐시 파일 최대5개·개별10MB·합계20MB까지 포함합니다.

학교 원본 링크의 익명 접근 검사는 실제 GPT 파일 읽기와 다릅니다. 로그인이나 POST가 필요한 자료는 직접 링크만으로 활용할 수 없을 수 있습니다.

[캠퍼스레이더 학업 도우미](https://chatgpt.com/plugins/plugins_6ae725ec935c8191903961d3fe1a1868)는 저장소 구조·최신성·출처를 확인하도록 안내하는 지침형 플러그인입니다. **현재 비공개이므로 링크만으로 다른 사용자가 설치할 수 있다고 보장하지 않습니다.** 일반 대화에서 자동 호출되는지도 별도 검증 대상입니다.

**현재는 수동 스냅샷입니다. Google 로그인·Drive 자동 업로드·여러 Google 계정 자동 전송은 아직 없습니다.** 해당 기능은 다음 작업으로 계획되어 있습니다. Claude·Gemini용 안내 구성도 제공 완료 상태가 아닙니다.

## 홈·잠금화면 위젯

더보기 → 화면·위젯에서 관련 설정과 안내를 확인합니다.

- **홈 위젯:** 홈 화면 위젯 선택기에서 캠퍼스레이더 할 일 또는 시간표 위젯을 추가합니다. 시간표에는 강의실을 표시하며 누르면 앱 시간표로 이동합니다.
- **표준 잠금화면 위젯:** 호환 Galaxy의 Good Lock → LockStar 위젯 추가에서 캠퍼스레이더 수업·마감(잠금화면용)을 배치합니다. 기기·지역·One UI·LockStar에 따라 지원이 다릅니다. 기본 시계 아래 미니 위젯에 자동 등록되는 의미는 아닙니다.
- **접근성 카드:** 앱에서 안내에 따라 접근성 서비스를 직접 켜는 별도 선택지입니다. 작은/전체 카드, 크기·위치·불투명도·숨김 조건을 설정합니다. 수업 카운트다운은 시작 후 유지 시간도 설정할 수 있습니다.

두 표시 방식은 별개이고 자동 전환하지 않습니다. Android에서 앱을 강제 종료하면 접근성 서비스를 다시 켜야 할 수 있습니다. 카메라·잠금 인증 화면과 다른 위젯의 간섭, AOD 등은 기기별 확인이 필요합니다. 표준 위젯을 접근성 카드 외형으로 통일하는 후속 개편은 아직 반영 전입니다.

## 계정과 자료 처리

- **학교 수집은 기기에서 학교 사이트로 직접 연결**합니다. 기본 수집·알림을 위해 별도 캠퍼스레이더 중계 서버 연결이 필수인 것은 아닙니다.
- 선택형 기존 서버 플러그인을 연결하면 동의한 학교 자료·첨부가 해당 서버로 전송됩니다. 수동 자료 내보내기에서는 사용자가 선택한 저장소로 전달합니다. 서버를 전혀 사용하지 않는다고 모든 기능을 일괄 설명할 수는 없습니다.
- 포털 ID·비밀번호와 Gemini 키는 운영체제 보안 저장소를 이용합니다. 수집 자료·설정·로그는 로컬에 저장하며 **모든 수집 자료가 별도로 암호화되는 것은 아닙니다.**
- 내부 AI 사용 시 필요한 공지·과제·과목·시간표·채팅 등 선택 기능의 자료가 Google Gemini로 전송됩니다. 학교 비밀번호·세션 쿠키를 AI에 보내는 기능은 아닙니다.
- 학교 계정과 로컬 데이터는 기기마다 독립적입니다. 시간표 공유는 사본이며 기기 간 전체 데이터 동기화가 아닙니다.
- APK 배포·업데이트 확인은 GitHub를 사용합니다. 학교 자료를 외부 연결에 전송하기 전에는 대상과 범위를 확인해 주세요.

## 업데이트

더보기 → 기록·지원 → **앱 업데이트**에서 정식만 받기/개발 버전도 받기를 선택하고 확인합니다. 자동 수집 때도 업데이트를 확인하고 새 버전 알림을 제공합니다. APK 다운로드·검증 뒤 Android 설치 화면에서 최종 확인합니다.

같은 위치의 **업데이트 내역**에서는 정식·개발 이력을 나누어 보고 건너뛴 버전의 변경도 확인할 수 있습니다. 이력 보기 모드와 받을 업데이트 채널은 별개입니다. 온라인 최신 이력은 배포 캐시에 따라 늦게 반영될 수 있습니다.

앱 삭제 없이 업데이트하는 것이 기본입니다. 정식 채널로 바꿔도 낮은 버전으로 자동 다운그레이드되지 않습니다. 이전 버전 설치는 OS 제한과 데이터 호환성을 따로 확인해야 합니다.

## 검증 범위와 알려진 제한

최신 개발 APK는 Flutter396개·Android 단위 테스트22개 통과, 정적 분석과 빌드·서명 검증을 마쳤습니다. Samsung Android17에서 누적 주요 경로와 최종 설치본의 시간표·공유 재읽기·위젯 강의실·개발 버전 표시·로그 저장을 확인했습니다. 전체 자동 테스트 통과가 모든 기기의 정상 동작을 의미하지는 않습니다.

장시간 USB 분리·재부팅·AOD·자연 마감 다중 알림, 태블릿·다른 계정, 일부 파일 형식/용량과 위젯 크기 조합, 두 기기 간 공유는 추가 검증이 필요합니다. 시간표 공유 최초 읽기 오류의 근본 원인은 미확정이고, 같은 원본의 중복 추출 등 후속 보완도 남아 있습니다. 자세한 내용은 [해당 릴리스](https://github.com/lemoncube7/campus-radar/releases/tag/v0.5.10-dev.9)를 참고하세요.

## 기존 iPhone·Windows 배포

신규 개발·버전 추종은 무기한 연기했으며 기존 파일만 유지합니다. 아래는 기존 배포 이용 안내로, 최신 Android 기능 지원을 뜻하지 않습니다.

- **iPhone:** [설치 안내](IOS-DISTRIBUTION.md)와 AltStore 배포를 따릅니다. 실제 설치 성공과 백그라운드 알림·WidgetKit·원격 업데이트/재서명 검증은 구분합니다.
- **Windows:** ZIP 전체를 고정 폴더에 풀고 `campus_radar.exe`를 실행합니다. EXE만 옮기지 마세요. WebView2 Runtime이 필요합니다. 닫으면 트레이에 남으며 완전 종료는 트레이 메뉴에서 합니다. 절전·종료 중에는 수집되지 않습니다. 자동 실행은 기존 버전의 PC 실행 설정에서 지정합니다.

## 소스와 개발

Flutter/Dart와 SQLite를 기반으로 하며 알림·캘린더·백그라운드·위젯은 각 플랫폼 네이티브 코드와 연결합니다.

현재 공개 저장소는 배포 파일·안내·워크플로와 기존 소스 ZIP 중심으로 관리됩니다. **저장소 루트에서 바로 Flutter 빌드하는 구조가 아니며, 기존 소스 ZIP이 최신 APK와 일치한다고 보장하지 않습니다.** 최신dev.9 릴리스 첨부는 APK와 해시이며 해당 버전의 소스 ZIP은 아직 게시하지 않았습니다.

소스 묶음을 사용할 때는 버전을 확인하고 압축 해제 후 `pubspec.yaml`이 있는 폴더에서 실행합니다.

```sh
flutter pub get
flutter analyze
flutter test
flutter build apk --release --dart-define=RELEASE_CHANNEL=development
```

학교 계정·API 키·개인 서명 설정은 소스에 포함하지 않습니다. 코드 변경·테스트 결과와 실제 공개 APK의 상태는 구분해 주세요.
